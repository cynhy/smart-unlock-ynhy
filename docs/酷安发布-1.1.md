# 蓝牙设备解锁 1.1：亮屏自动输 PIN，稳定到没脾气

> 适用：Android 8.0 ～ 16
> 需要：Shizuku（不用 root、不用电脑）

## 它解决什么问题

每天早上拿起手机，亮屏、上滑、输 6 位 PIN，一天要重复几十次。

装这个 APK 之后，只要指定的蓝牙设备连着（手表、耳机、手环都行），屏幕一点亮，它就把 PIN 替你输完，直接进桌面。实测 550～1070ms。

不挑品牌，小米手环、华为手表、AirPods、车载蓝牙都能用。

## 这一版能做什么

- 亮屏自动解锁，最快半秒进桌面
- 任意已配对蓝牙设备，逐个勾选，没勾的不参与
- 多设备判定：任一在线，或者要求全部在线
- Wi-Fi 也能单独当解锁条件；也能反过来当「必要条件」
- SIM 卡 PIN 防呆：SIM 锁着时不动手，避免把手机 PIN 输进 SIM 界面
- 临时暂停 15 分钟 / 1 小时 / 4 小时，重启不丢
- 独立日志页，出问题能自己看
- 一键清理，停进程删配置
- 中英双语，跟系统走

## 三个前提

1. 锁屏必须是 **PIN 码（纯数字）**，图案锁和混合密码不行。
2. 装好 **Shizuku** 并让它跑起来（不需要 root）。
3. 设备已经在系统蓝牙里配对过，Wi-Fi 至少连过一次。

## 稳定性

这一版只走 Shizuku 一条路，逻辑简单，跑了一个多月没有出现解锁失败、误触发、掉进程的问题。

**没有发现明显缺陷。**

要说限制，只有两个：

- 它判断的是「蓝牙还连着」，不是「手表还戴着」。表摘下来放桌上，只要没断连，手机照样解锁。
- Wi-Fi 只能添加「当前已连接」的那个，不支持手动敲 SSID。

## 适合谁

只想要最稳的自动解锁，不折腾 Root，也不需要无线调试的人。

## 安装

- 2.0 是调试签名、3.0 测试版是另一把测试密钥，都不能与 1.1 互相覆盖；1.1 与 3.3 及之后的正式版签名一致，可直接覆盖升级。
- 只有跨签名（例如从 2.0 / 3.0-test 换到正式版）才需要先卸载；卸载会清空勾选的设备和设置，升级前记一下 PIN 和目标设备名。
- 装完记得把 Shizuku 和本应用都加进电池白名单，否则后台会被系统回收。
