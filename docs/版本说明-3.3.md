# 版本说明 · 3.3（推荐版）

> **适用安卓版本：Android 8.0 ～ 16（minSdk 26，targetSdk 34）**
> 三档授权全部可用；其中「内置无线调试」需要 **Android 11 及以上**（系统自带无线调试功能起始版本）。
> 实测环境：Android 12、Android 13、Android 14、Android 16（LineageOS / HyperOS）。

## 一句话概括

3.3 **完整包含 1.1 的全部功能**，并在此之上增加了三档授权、音乐锁屏返回、震动反馈、公告栏和 ADB 命令行。新加入的功能中有一部分成熟度还不算高，但核心解锁链路与 1.1 一致，**总体仍推荐使用 3.3**。

## 1.1 已有的功能（3.3 全部保留）

- 亮屏自动解锁，实测 550～1070ms
- 任意已配对蓝牙设备，可多选，任一在线 / 全部在线
- Wi-Fi 独立解锁 + Wi-Fi 必要条件
- SIM 卡 PIN 防呆
- 临时暂停（15 分钟 / 1 小时 / 4 小时）
- 三级设置页与日志页、一键清理、中英双语

## 3.3 新增的功能

| 功能 | 成熟度 | 说明 |
| --- | --- | --- |
| 三档授权（Shizuku / Root / 无线调试） | 前两档稳定，无线调试中等 | 设置页可随时切换，切换后需重新部署 |
| 音乐锁屏返回 | 中等 | 解锁后可按包名打开指定应用，或向右滑动；两者同时开启时优先打开应用。不同 ROM 的音乐锁屏实现差异较大，效果可能不一致 |
| 震动反馈 | 稳定 | 按键与开关轻微震动，可在设置内关闭 |
| 公告栏 | 稳定 | 测试包说明、注意事项、开源组件鸣谢（蓝字可查看许可协议） |
| ADB 命令行 | 中等 | 无线调试页顶部可直接执行 `adb shell` 命令；需先完成配对连接 |
| Root 授权 | 稳定（视设备） | 直接 `su -c` 执行，不需要 Magisk 模块；部分 ROM 的 su 只对 adb 开放时不可用 |

## 稳定性建议（重要）

为了稳定，**改动任何选项后请回到主页重新点「部署并启用」**。设置项变化会立即重写配置并重启守护，但重新部署能同时清理上一轮的运行残留（旧守护进程、旧 logcat 监听、跨进程锁与在线判定缓存），避免新旧状态混用。

- 部署与重启会清理运行残留，但**不会**清除你的设置、设备勾选与日志。
- 3.3.3 起，部署与重启都会清掉旧的在线缓存，不会再出现「设备其实已断开却仍解锁」的情况。
- 切换授权方式后同样需要重新部署一次。

## 三档授权怎么选

| 方式 | 需要什么 | 稳定性 | 适合 |
| --- | --- | --- | --- |
| Shizuku（默认） | 装 Shizuku 并授权 | 最稳 | 大多数用户 |
| Root | Root 管理器里允许本应用 | 稳定，取决于 su 实现 | 已 root 的设备 |
| 无线调试 | 开发者选项里配对一次 | 中等，依赖端口与配对状态 | 不想装 Shizuku 也不能 root |

三种方式执行同一套守护脚本，区别只在「谁给 shell 身份」。无线调试档内置 Kadb ADB 客户端，因此包体更大（约 3.3 MB），且配对端口与连接端口不是同一个数字。

## 前提条件

1. 锁屏方式为 **PIN 码（纯数字）**。
2. 目标设备已配对 / Wi-Fi 已连接过一次。
3. 所选授权方式可用：Shizuku 在运行，或已授予 Root，或无线调试已配对。

## 已知问题与注意事项

- **无线调试档**：配对成功但连接失败时，先在开发者选项里关闭再打开「无线调试」，然后重新配对；系统重启后端口会变，需要重新连接。
- **音乐锁屏返回**：部分机型（尤其自带音乐锁屏的 ROM）右滑手势可能被系统接管；此时优先使用「打开指定应用包名」。
- **Root 档**：开发者选项里 Root access 需设为「Apps and ADB」，否则会显示 `Root unavailable`。
- **切换授权方式**：不会自动迁移运行中的守护，需要重新点「部署并启用」。
- **后台限制**：HyperOS / ColorOS 等需要在电池设置里允许自启动与后台运行，否则 Shizuku 会被回收。

## 签名与升级

- 3.3 使用**正式密钥**签名；3.0 测试版使用测试密钥签名，两包**不能互相覆盖**。
- 从 1.1 / 2.0 升级到 3.3 需要先卸载旧包（签名不同），卸载会清空设备勾选与设置。
- 想保留配置的话，升级前把 PIN、目标设备名称、Wi-Fi 名称记下来。

## 推荐结论

- 只想要最稳、功能最少：**1.1**
- 需要无线调试 / Root / 音乐锁屏返回 / ADB 命令行：**3.3**（推荐）
- 3.3 的新增功能里，无线调试与音乐返回在个别 ROM 上可能需要手动微调，其余功能与 1.1 同等稳定。
