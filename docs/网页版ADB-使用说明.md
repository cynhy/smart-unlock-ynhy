# 网页版 ADB 使用说明（免回环端口）

> 适用版本：Smart Unlock 6.3.7 及以上  
> 入口：本应用 → 无线调试页 → 最下方「网页版 ADB（USB，免回环端口）」

## 这是什么

谷歌可能进一步收紧「本机回环 ADB」（`127.0.0.1`）的配对与授权。网页版 ADB 是备用通道：不经过手机自己的 adbd 回环端口，而是用 **WebUSB** 把目标安卓设备直接连到另一台设备，在浏览器里执行 ADB 命令。

## 归属与版本

- 网页由 **晨钟酱（CzJam）** 所有并维护，版本 **6.3.9**；
- 属于开源项目 **《搞机工具箱》Web 版**，许可证 **GPL-3.0**；
- 在线地址：<https://czjam.github.io/gjgjxweb/>
- 开源仓库：<https://github.com/CzJam/gjgjxweb>

Smart Unlock 只提供入口和使用说明，**没有内置、也没有修改其网页代码**，与晨钟酱无隶属关系。网页的可用性、内容与数据安全由该网页自行负责。

## 能用在哪

| 角色 | 要求 |
| --- | --- |
| 主机（打开网页的一端） | **除 iOS 以外的设备**：Windows、macOS、Linux、Android 平板或另一台手机 |
| 浏览器 | Chrome、Edge、Brave、Opera 等 Chromium 内核且支持 WebUSB |
| 不支持 | iOS（浏览器没有 WebUSB）、Firefox（不支持 WebUSB） |
| 被调试端 | 安卓设备，开发者选项打开「USB 调试」 |
| 连接 | 数据线；手机主机用 OTG 转接头；两台手机用 C-to-C 数据线 |

## 步骤

1. 目标安卓：开发者选项 → 打开「USB 调试」；
2. 连接数据线；
3. 在主机 Chrome / Edge 打开 <https://czjam.github.io/gjgjxweb/>（首次加载需联网）；
4. 点网页里的「连接」→ 选择 USB 设备 → 在目标手机上允许 USB 调试授权；
5. 在网页的 ADB 终端执行命令。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 网页没有「连接」按钮 / 找不到设备 | 换 Chrome / Edge；确认浏览器版本支持 WebUSB；Firefox、iOS 不行 |
| 设备列表为空 | 换一根支持数据传输的线；手机主机换 OTG 转接头；确认目标端已开 USB 调试 |
| 连接后马上断开 | 供电不足或线材问题；换 OTG / 换电脑 USB 口 |
| 目标端没有 RSA 弹窗 | 撤销 USB 调试授权后重插；或在开发者选项点「撤销 USB 调试授权」再试 |
| 网页打不开 | 首次加载必须联网；检查网络或稍后重试 |
| 能连上但命令无输出 | 确认在网页的 ADB 终端里执行；部分命令需要目标端系统权限 |

## 安全提醒

- 只从官方地址进入网页；
- 网页首次加载需要联网；Smart Unlock 本身不联网、不上传数据，打开后由浏览器直接与设备通信；
- 不要把 USB 调试授权长期留给不信任的主机；
