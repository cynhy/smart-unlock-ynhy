# 版本说明 · 1.1（稳定版）

> **适用安卓版本：Android 8.0 ～ 16（minSdk 26）**
> 实测环境：Android 12（EMUI 12）、Android 13、Android 16（HyperOS 3），均为 Shizuku 授权路径。

## 一句话概括

只依赖 Shizuku 的基础版：亮屏自动输 PIN，功能不多但跑得稳，**没有发现明显缺陷**，适合只需要「自动解锁」这一件事的用户。

> **推荐使用 3.3.3**：它包含 1.1 的全部功能，并已修复部署后沿用旧在线缓存导致的误解锁。1.1 适合只需要基础解锁、或环境不满足 3.x 的情况。

## 包含的功能

| 能力 | 说明 |
| --- | --- |
| 自动解锁 | 亮屏触发，实测 550～1070ms 进入桌面 |
| 任意蓝牙设备 | 已配对的耳机、手表、手环、音箱、键盘都可以，不限品牌 |
| 逐设备启用 | 未勾选的设备不参与判定，新设备默认不勾 |
| 多设备判定 | 任一在线（默认）或全部在线（AND） |
| Wi-Fi 独立解锁 | 只连指定 Wi-Fi 也能解锁，不需要蓝牙设备 |
| Wi-Fi 必要条件 | 反过来要求「必须连在指定 Wi-Fi」才解锁 |
| SIM 卡 PIN 防呆 | SIM 处于 PIN 锁定时跳过注入，避免把手机 PIN 输进 SIM 界面 |
| 临时暂停 | 15 分钟 / 1 小时 / 4 小时，重启不丢 |
| 设置页 / 日志页 | 三级页面，日志 2.5 秒自动刷新 |
| 一键清理 | 停进程、删配置，保留勾选 |
| 中英双语 | 跟随系统语言，可手动切换 |

## 前提条件

1. 锁屏方式为 **PIN 码（纯数字）**，图案锁与混合密码不支持。
2. 已安装并运行 **Shizuku**（不需要 root）。
3. 目标设备已在系统蓝牙里配对，或 Wi-Fi 已连接过一次。

## 已知限制

- 判断的是「设备是否保持连接」，不是「是否戴在身上」。手表放桌上只要蓝牙不断，照样会解锁。
- 只支持 Shizuku 一档授权，Shizuku 被系统回收后需要重新激活。
- Wi-Fi 列表只能添加「当前已连接」的网络，不支持手动输入 SSID。

## 适合谁

只要最稳的自动解锁、不想折腾授权方式、设备上没有 root 也不需要无线调试的用户。

## 安装提示

- 与 2.0 / 3.x 的签名不同，**不能覆盖安装**；从 1.1 升级到 3.3 必须先卸载 1.1。
- 卸载会清空应用内已勾选的设备与设置，升级前请先记下 PIN 与目标设备名称。
