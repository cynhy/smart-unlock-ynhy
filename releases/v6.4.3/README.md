## 本版修复

### 无线调试

- 重写 mDNS 发现：解析队列、解析失败重试、发现启动失败重试，修掉长时间搜不到配对服务。
- 连接端口从配对服务启动时就并行发现并缓存；配对成功后优先使用缓存端口或上次端口，25 秒内持续等待新端口，不再过早报“没找到连接端口”。
- 连接失败不再立刻终止：继续等待新端口；超时后才提示回应用手动填写端口，通知正文可直接点回应用。
- 通知不再反复重建：相同状态不刷新通知，避免内联输入框被收起、发送按钮需要猛点。
- 新增「大按钮输入」动作：打开独立输入页，大号「发送」按钮点一次即提交；页面提示推荐分屏 / 小窗，避免离开设备码页面后卡片收起、配对码失效。

### 网页版 ADB

- 新增「两台手机互连（推荐用法）」：主机手机装本应用并用 Chrome / Edge 打开网页，C-to-C 线或 OTG 接被控手机，被控手机开 USB 调试并允许授权。
- 新增 9 张可复制 ADB 指令卡片：检查连接、看机型、确认已装、允许通知、电池白名单、后台运行、打开应用、启动 Shizuku、看守护日志。

## 升级须知

- 与 6.3.6 / 6.3.9 使用同一正式签名，可直接覆盖安装（versionCode 643）。
- 安装后请打开应用点一次「部署并启用」（守护脚本随 APK 更新）。

## 已知问题

- 无线调试需要 Android 11+，每次重启后需要重新配对。
- 进入系统「使用配对码配对设备」后，建议用分屏或小窗操作本应用；离开设备码页面后卡片可能收起，配对码会立即失效。
- 首次配对会解压约 4.5MB 的 adb 依赖库，需要几秒。
- 网页版 ADB 首次加载必须联网；iOS / Firefox 不能作主机。

