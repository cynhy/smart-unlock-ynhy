## 本版重点

### 无线调试内核（6.3.7 起重写，6.3.9 沿用）

- 移除第三方 Kadb / Kotlin / Bouncy Castle / Okio；
- 改为随包打包的**官方 AOSP adb 客户端**（Termux android-tools 37.0.0p1 构建，Apache-2.0）；
- 可执行文件 `lib/arm64-v8a/libadb.so`（安装后解压到 `nativeLibraryDir`）；
- 依赖库 `assets/adb-libs.zip`（首次使用解压到应用私有目录并设为只读）；
- 以应用自身 uid 执行 `adb pair` / `adb connect` / `adb shell` / `adb push`；
- 配对入口不变：通知输入 6 位配对码，或分屏 +「手动配对」；
- 每条命令显式使用 `-P 5039`，避免与系统 5037 端口混用。

### Root 稳定性

- 常驻 `su` 交互 shell，不再每次操作重新拉起 su；
- 每条命令写入唯一脚本文件，修掉并发覆盖；
- 首次授权等待 15 秒，失败缓存 20 秒，成功缓存 5 分钟；
- 守护用 `setsid` 脱离 `su` 会话；
- Root 状态检测移出 UI 线程；
- 设置页新增「检测 Root 授权」。

### 网页版 ADB（备用通道）

- 入口：设置 → 授权方式第 4 项（仅入口，不改授权方式）；点进去是说明页，再打开网页；
- 不依赖本机回环 ADB，WebUSB 直连安卓设备；
- 主机：除 iOS 外的设备 + Chrome/Edge 等 Chromium 浏览器；
- 被调试端：Android + USB 调试；
- 网页归属：晨钟酱（CzJam），版本 6.3.9，《搞机工具箱》Web 版，GPL-3.0；
- **仅链接，未打包、未修改其代码**；网页工具的 6.3.9 与本应用 6.3.9 只是数字相同，没有关联。

## 升级须知

- 6.3.9 与 6.3.6 使用同一正式签名，可直接覆盖安装；
- 已安装 6.3.7（637）也可直接覆盖升级到 639；
- 安装后请打开应用点一次「部署并启用」（守护脚本随 APK 更新）；
- 1.1 与正式包同一签名，可直接覆盖升级；从 3.0-test（测试密钥）或 2.0（调试签名）升级需要先卸载。

## 已知问题

- 内置无线调试需要 Android 11+，且每次重启后需要重新配对；
- 配对时不能离开系统「使用配对码配对设备」弹窗，否则端口和配对码会立即失效；
- 首次配对会解压约 4.5MB 的 adb 依赖库，需要几秒；
- 网页版 ADB 首次加载必须联网；iOS / Firefox 不能作为主机；
- Root 稳定性仍取决于具体 root 实现；若异常请附 `wu.log` 中的 `su` / `timing` 行；
- 3.3.3 及以前的旧版说明中的部分行为已过时，以 `docs/使用说明.md` 为准。
