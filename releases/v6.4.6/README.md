# v6.4.6（推荐版本）

> **状态：目前推荐使用 6.4.6。** 其余版本可能存在功能缺陷或安全性漏洞，仅作历史留存。正式签名包已由维护者签名并上传；**未签名包不会发布**。
>
> **Android 17 / 澎湃 4 必须使用本版。** 6.4.3 及更早版本在 Android 17 上无法识别锁屏状态，会完全不解锁；请同时保持「设置 → 解锁增强 → Android 17 适配」开启。
>
> **无线调试：6.4.0 之前的所有版本（含 6.3.9）都存在已知 bug，可能无法配对或连接。** 需要无线调试请使用 6.4.0 及以后（推荐 6.4.6）。

## 本版内容

6.4.6 是 **Android 17 / 澎湃 4 的兼容补丁**；Android 8.0 – 16 上的行为与 6.4.3 一致。三档授权方式、蓝牙 / WiFi 条件、延长解锁等功能均未改动。

### 修了什么

| Android 17 的变化 | 6.4.3 的表现 | 6.4.6 的处理 |
| --- | --- | --- |
| `dumpsys window policy` 移除 `mIsShowing` | 误判为「未锁屏」，直接跳过 | 改用 `KeyguardServiceDelegate showing=` 判定，焦点窗口兜底 |
| 不再输出 `power_screen_state` 事件 | 亮屏没有触发源 | 增加 0.9 秒低频轮询兜底，边沿触发 |
| 后台收不到 `ACTION_SCREEN_ON` | 应用侧亮屏链失效 | 应用亮屏链 + 守护轮询双通道 |

### 其他改进

- 密码键盘改为**等待焦点后再注入**，减少 `input text` 打错窗口；
- 音乐锁屏等全屏 Activity 抢占焦点时会先等键盘出现，`occluded=true` 不再被当成已解锁；
- 密码锁屏是 secure window，`uiautomator dump` 拿不到键盘，`keypad_present` 回退为 `locked && bouncer_ready`；
- 新增设置项「解锁增强 → **Android 17 适配**」（`A17_COMPAT`，默认开启）。关闭后不轮询、不等焦点、解锁更快，但在 Android 17 上会完全不解锁；
- `wu-daemon.sh --check` 增加 `a17_compat` 字段，启动日志带 `a17=1`。

## 实测

| 场景 | 结果 |
| --- | --- |
| 关屏 → 亮屏 | 解锁成功，约 370–620ms |
| `am force-stop` 后关屏 → 亮屏 | 解锁成功，约 760ms |
| 关闭「Android 17 适配」 | 8 秒以上无触发，屏幕保持锁定 |

> 测试机型：24129PN74C，HyperOS 4 / Android 17，`OS4.0.4.0.XOCCNXM`。其他机型可自行测试关闭适配后是否正常。

## 升级须知

- 与 6.4.3 使用同一正式签名，可直接覆盖安装（versionCode 646）。
- 安装后请打开应用点一次**「部署并启用」**：守护脚本随 APK 更新，旧脚本不会自动替换。
- 升级后确认「设置 → 解锁增强 → Android 17 适配」为开启状态。
- 如果想回退到 6.4.3，需覆盖安装 6.4.3 并重新「部署并启用」。

## 已知问题

- 仅支持 4–16 位纯数字 PIN；不支持图案 / 混合密码 / 纯生物识别。
- 重启后守护不会自动复活，需要重新授权并部署。
- 无线调试需要 Android 11+，每次重启后需要重新配对，端口会变。
- 延长解锁为实验性功能；清除密码期间指纹 / 人脸会失效，异常时可能无法自动恢复。
- 未在 Android 8–16 多机型上做回归测试。
