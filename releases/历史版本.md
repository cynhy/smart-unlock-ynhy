## 版本备注

- **1.1**：仅 Shizuku；蓝牙 / Wi-Fi 解锁、SIM PIN 防呆、三级设置页。
- **3.0-test**：首次引入 Root、内置无线调试、音乐锁屏返回；测试密钥签名。
- **3.3**：与 3.0 功能一致，改用正式密钥。
- **3.3.3**：修复重新部署后沿用旧在线缓存导致误解锁。
- **3.6 / 3.8 / 3.8.6 / 3.8.8 / 3.9 / 6.3.3**：3.x 至 6.x 的过渡版本；3.8 引入应用选择页、打开指定应用、增强防护等，3.8.6 / 3.8.8 修复应用选择与 resolver 问题。保留用于回溯，不承诺稳定。
- **6.3.6**：修复头部 MAC 解析与配对通知；当前推荐稳定版。
- **6.3.7**：Root 常驻连接与并发修复；新增网页版 ADB 入口；测试版。

## 升级与签名

- 1.1、3.3 及之后的正式包使用同一证书，可直接覆盖升级；Android 仍会阻止版本号降级。
- 2.0（调试签名）与 3.0-test（测试签名）不能覆盖正式包；切换前需卸载，应用内设置会丢失。
- 校验命令：

```powershell
apksigner verify --print-certs watch-unlock-6.3.6-signed.apk
Get-FileHash watch-unlock-6.3.6-signed.apk -Algorithm SHA256
```
