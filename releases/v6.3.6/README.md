# v6.3.6（稳定）

> **稳定版。** 官方标注的稳定版为 **1.1、3.3.3、6.3.6**。

## 下载

| 文件 | 说明 |
| --- | --- |
| `watch-unlock-6.3.6-signed.apk` | 正式签名包 |

- versionCode：636
- versionName：6.3.6
- minSdk：26 / targetSdk：34

## 修复

- StateMachine 头部 MAC 解析取错字段（把 `for` 当 MAC），部分机型始终判定不在线、完全无法解锁；
- 配对通知正文会打开应用，离开系统配对弹窗导致配对码失效；
- 提升 versionCode 以覆盖已安装的 6.3.3。

## 升级

- 与 6.3.3 同一正式签名，可直接覆盖；
- 安装后点一次「部署并启用」。

## 说明

6.3.6 的完整使用说明见 [docs/使用说明-6.3.7.md](../../docs/使用说明-6.3.7.md)；6.3.7 新增的 Root 修复与网页版 ADB 不包含在 6.3.6 中。
